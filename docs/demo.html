Why the governed model scored this

Exact per-feature contribution to the log-odds. For a linear model these are the Shapley values — computed in closed form, not sampled.

Scoring runs entirely in your browser. The standardizer, coefficients and isotonic calibration curve are exported from the trained scikit-learn pipeline by src/export_web_model.py, which aborts unless this arithmetic reproduces predict_proba on all 2,400 test applicants — it currently matches to 0.00e+00, bit for bit.

Synthetic data throughout. Reference implementation — not a hiring tool, and not approved for production use.
