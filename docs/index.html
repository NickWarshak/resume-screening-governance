The central finding

The model that best predicts historical recruiter decisions is not the model that best identifies qualified candidates.

Two models were trained on the same applicant population. The naive model scores higher against recruiter decisions (AUC 0.911 vs 0.865) and lower against true qualification (0.915 vs 0.961). In production only the first number is observable — so standard model selection, done correctly by every engineering measure, ships the discriminatory model. Accuracy against a biased label is not a measure of quality; it is a measure of fidelity to the bias.

Training data is a synthetic population of 12,000 applicants in which latent qualification is known and generated independent of protected class — so every disparity the audit finds is measurement bias by construction.

What this project does not claim

  1. The governed model still fails the four-fifths rule intersectionally for Female / Hispanic-Latino applicants (0.652; 95% CI 0.370–0.949; 87% bootstrap probability of a genuine breach). It passes marginal audits while failing this intersection. Disclosed, not resolved.
  2. years_experience remains age-correlated (1.47 SD gap across age groups). Retained on business-necessity grounds and monitored quarterly — a live ADEA exposure, not a solved problem.
  3. Training data is synthetic. The metrics demonstrate the governance method; they do not transfer to a real applicant pool.
  4. The system is suitable for ranking and routing under human review, not automated rejection. The architecture contains no REJECT code path.

Reproducing

Every figure and statistic on this site is generated by the accompanying code, seeded at 42, and gated by an automated check that 64 report claims match the computed metrics.

pip install scikit-learn pandas numpy matplotlib shap scipy joblib
cd src
python3 generate_data.py && python3 train.py && python3 fairness.py \
  && python3 significance.py && python3 explain.py && python3 monitor.py \
  && python3 sustainability.py && python3 figures.py
cd ../tests && python3 verify_report.py     # 64/64 checks

Generated datasets and trained model artifacts are intentionally excluded from the repository; they rebuild deterministically from the commands above.

Status. Reference implementation for governance demonstration. Not approved for production use, and not a hiring tool. Training data is synthetic; no real applicant data was used at any stage.
